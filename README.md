# Классификация символов на C

Проект реализует адаптивную полносвязную нейронную сеть на языке C для классификации рукописных цифр MNIST. Архитектура сети задаётся через конфигурационный файл, обучение выполняется с помощью SGD, а результаты сохраняются в виде текстовой и графической визуализации.

## Что Реализовано

- динамическая архитектура из `config.txt`, например `neurons: 784, 64, 10`;
- прямой проход: ReLU на скрытых слоях, softmax на выходном слое;
- обратное распространение ошибки;
- SGD-обучение;
- L2-регуляризация;
- добавление шума: 5-10% пикселей меняются на `+-0.2`;
- загрузка MNIST из CSV;
- вывод ошибки cross-entropy каждые 10 эпох;
- вывод вероятностей классов после обучения;
- экспорт активаций скрытого слоя в `heatmap.txt`;
- экспорт grayscale-визуализации в `heatmap.pgm`;
- экспорт истории ошибки в `loss_history.txt`;
- экспорт истории ошибки и точности в `metrics_history.txt`;
- Python-визуализация графиков loss, accuracy и heatmap;
- автоматические проверочные тесты.

## Данные

Используется MNIST в CSV-формате. Каждая строка содержит метку класса `0..9`, затем 784 значения пикселей изображения 28x28. При загрузке пиксели автоматически нормализуются из диапазона `0..255` в `0..1`.

Также реализован синтетический режим, который генерирует простые пиксельные паттерны. Он нужен для быстрой проверки программы без датасета.

Архивы `mnist_train.csv.zip` и `mnist_test.csv.zip` лежат в корне проекта. Для распаковки:

```powershell
.\scripts\prepare_data.ps1
```

После этого появятся:

- `data/mnist_train.csv`;
- `data/mnist_test.csv`.

## Архитектура Сети

Архитектура задаётся в конфигурационном файле:

```text
neurons: 784, 64, 10
```

Это означает:

- 784 входных нейрона для изображения 28x28;
- один скрытый слой из 64 нейронов;
- 10 выходных нейронов для цифр MNIST.

Можно задать несколько скрытых слоёв:

```text
neurons: 784, 128, 64, 10
```

Основные параметры:

```text
learning_rate: 0.01
regularization: 0.0005
epochs: 20
train_samples: 2000
val_samples: 500
noise_fraction: 0.08
noise_delta: 0.2
```

## Алгоритм

Для скрытых слоёв используется ReLU:

```text
ReLU(x) = max(0, x)
```

Для выходного слоя используется численно устойчивый softmax. Функция потерь - cross-entropy. Обучение выполняется методом SGD после каждого примера. В градиент весов добавляется L2-регуляризация:

```text
gradient = gradient + regularization * weight
```

Перед обучением к тренировочным данным применяется шум: заданная доля пикселей меняется на `+-noise_delta`. В основном конфиге `noise_fraction: 0.08` и `noise_delta: 0.2`, что соответствует требованию изменить 5-10% пикселей на `+-0.2`.

## Сборка

Обычная сборка через GCC:

```powershell
gcc -std=c11 -O2 -Wall -Wextra -pedantic -Iinclude src/*.c -o nn_classifier.exe -lm
```

Сборка через CMake:

```powershell
cmake -S . -B build
cmake --build build
```

## Запуск

Запуск на MNIST:

```powershell
.\nn_classifier.exe config.txt
```

Более долгий запуск с большей сетью:

```powershell
.\nn_classifier.exe config_bigger_mnist.txt
```

Проверка без внешних данных:

```powershell
.\nn_classifier.exe config_synthetic.txt
```

## Тестирование

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\tests\run_tests.ps1"
```

Тесты собирают программу, запускают синтетический режим, быстрый MNIST CSV-режим, проверяют создание `heatmap.txt`, `heatmap.pgm`, `loss_history.txt`, `metrics_history.txt`, а также проверяют ошибку на некорректном конфиге.

## Визуализация

После запуска появляются:

- `heatmap.txt` - численные активации первого скрытого слоя;
- `heatmap.pgm` - grayscale-картинка этих активаций;
- `loss_history.txt` - CSV-таблица `epoch,loss` для построения графика ошибки;
- `metrics_history.txt` - CSV-таблица `epoch,loss,train_acc,val_acc` для графиков ошибки и точности.

Одна строка heatmap соответствует одному примеру из проверочного набора, один столбец - одному нейрону скрытого слоя.

HTML-визуализация строит три блока: график loss по эпохам, график accuracy по эпохам и тепловую карту активаций. На графиках loss и accuracy эпохи явно подписаны по оси X.

Python-визуализация:

```powershell
py .\scripts\plot_results.py --input-dir . --output-dir visualization
```

После этого откройте:

```text
visualization/index.html
```

Через CMake можно запустить обучение и визуализацию одной командой:

```powershell
cmake --build build --target run_and_visualize
```

Если обучение уже запускалось и нужно только обновить графики:

```powershell
cmake --build build --target visualize
```

## Важные Функции

### `src/main.c`

- `main` - точка входа. Загружает конфиг, подготавливает данные, создаёт нейросеть, запускает обучение, экспортирует визуализацию и печатает вероятности классов.

### `src/config.c`

- `set_defaults` - задаёт значения по умолчанию для конфигурации.
- `trim` - убирает пробелы в начале и конце строки.
- `parse_neurons` - разбирает список слоёв из строки `neurons`.
- `parse_data_mode` - определяет режим данных: synthetic, csv или mnist.
- `load_config` - читает `config.txt` и заполняет структуру `Config`.
- `free_config` - освобождает память, выделенную под список слоёв.
- `print_config` - печатает параметры запуска.

### `src/data.c`

- `dataset_init` - создаёт матрицы признаков и one-hot меток.
- `dataset_free` - освобождает память набора данных.
- `build_pattern` - строит синтетический паттерн для класса.
- `generate_synthetic` - создаёт синтетический набор данных.
- `apply_noise` - добавляет шум во входные данные.
- `load_csv_file` - загружает MNIST CSV и нормализует пиксели.
- `load_mnist_idx` - загружает классический бинарный IDX-формат MNIST.
- `load_or_generate_datasets` - выбирает источник данных по конфигу.

### `src/matrix.c`

- `matrix_create` - создаёт матрицу.
- `matrix_free` - освобождает матрицу.
- `matrix_fill` - заполняет матрицу одним значением.
- `matrix_random` - заполняет матрицу случайными числами.
- `matrix_get` и `matrix_set` - читают и записывают элементы матрицы.

### `src/nn.c`

- `relu` и `relu_derivative` - функция активации и её производная.
- `softmax_stable` - преобразует выходы сети в вероятности классов.
- `init_layer` - инициализирует веса и bias слоя.
- `network_init` - создаёт нейросеть по конфигу.
- `network_free` - освобождает память нейросети.
- `forward_sample` - выполняет прямой проход для одного примера.
- `cross_entropy_one` - считает ошибку cross-entropy.
- `l2_penalty` - считает L2-штраф по весам.
- `backprop_sample` - выполняет обратное распространение ошибки.
- `compute_grads` - считает градиенты весов и bias.
- `sgd_step` - обновляет параметры сети методом SGD.
- `evaluate_accuracy` - считает точность на наборе данных.
- `train` - основной цикл обучения; сохраняет `loss_history.txt` и `metrics_history.txt` для графиков.
- `export_heatmap` - сохраняет активации скрытого слоя в `heatmap.txt`.
- `export_heatmap_pgm` - сохраняет активации в виде изображения `heatmap.pgm`.
- `print_sample_probabilities` - печатает вероятности классов для нескольких примеров.

### `src/util.c`

- `xmalloc` и `xcalloc` - безопасное выделение памяти.
- `xfree` - освобождение памяти.
- `seed_rng` - инициализация генератора случайных чисел.
- `rand_uniform` - случайное число из заданного диапазона.

### `scripts/plot_results.py`

- `read_metrics` - читает loss, train accuracy и validation accuracy из `metrics_history.txt`.
- `read_loss_only` - читает старый формат `loss_history.txt`, если `metrics_history.txt` отсутствует.
- `read_heatmap` - читает активации из `heatmap.txt`.
- `write_index` - создаёт HTML-страницу с интерактивными графиками loss, accuracy и heatmap.
